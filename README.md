## 📌 About Me
- I am a Chartered Accountant with passion for serious coding. I started learning to code as a hobby and then slowly I incorporated it into my daily work in my job utilising it to automate the audit work. The more I used the coding to automate the audit work the more i got interested in finding out what more can I build with it or do with it. I built custom automation tools like ledger reconciler, inventory reconcilier, automated internal control testing. Slowly, I built system that aimed at not relying much on sampling which has been the traditional way of auditing. This has helped me gain more confidence on the audits i performed.
- My interest in performing  more in-depth audits caused me to explore natural language processing and soon i started to learn about machine learning and deep learning and completed the respective courses for it and later started to learn how to build an LLM from scratch and its tokenizer from scratch and built both of them which is in my pinned repos.
- I slowly started building out mobile apps with react native, and web apps with react and next js and built some apps that serve me well in my daily life for my requirements.
- Now, I have gained more interest in systems programming langauges and started learning rust and built my own minigrep tool that can search for words in the contents of the files and give out name of files that contain the query word. And i am continuing to learn and explore this language as well for desktop applications.
